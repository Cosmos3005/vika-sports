VIKA SPORTS v0.2

Быстрый запуск Windows:
1. Установи Python 3.11+.
2. Двойной клик по START_VIKA.bat.
3. Откроется http://127.0.0.1:8080

Сайт работает без обязательных API-ключей в demo/fallback режиме.

Бесплатные источники:
- ESPN public scoreboard через локальный прокси.
- TheSportsDB free v1 API.
- API-Football Free: 100 запросов/день после регистрации.

Важно: реальные лимиты и доступность бесплатных источников зависят от их условий и покрытия.
